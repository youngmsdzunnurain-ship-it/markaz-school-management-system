
## The consistent page header
One banner (night sky, moon, mosque skyline, green / gold / white) and one top bar (dark green with a gold line and the same
avatar button) are used on every dashboard and staff page. They are generated by `python3 tools/header/make-header-css.py`
into `public/css/page-header-2026.css`. To change the colours, sizes, lettering or the skyline drawing, edit that script and run it.
A new page uses the design by adding its banner class to the `BANNERS` list in the script and the one stylesheet link line.
